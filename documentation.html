2. Image & PDF Tools

2.1 Photo to PDF Converter

  1. Open the Photo to PDF tool.
  2. Select one or more images from your device.
  3. Arrange images in the correct order.
  4. Click the convert button.
  5. Download the final PDF file.

2.2 PDF Compressor

  1. Select a PDF document.
  2. Choose the desired compression level.
  3. Click compress.
  4. Download the optimized PDF.

2.3 Merge PDF

  1. Select multiple PDF files.
  2. Arrange them in the correct sequence.
  3. Click merge.
  4. Download the merged document.

2.4 PDF to Image

  1. Select a PDF file.
  2. Choose image output format.
  3. Convert each page into images.
  4. Download images individually or as a ZIP.

2.5 Image Format Converter

  1. Upload an image.
  2. Select the target format (JPG, PNG, WEBP).
  3. Convert the image.
  4. Download the converted file.

2.6 Image Resizer

  1. Upload an image.
  2. Enter width and height values.
  3. Resize the image.
  4. Download the resized image.

2.7 Photo Size Compressor

  1. Select an image.
  2. Adjust compression quality.
  3. Compress the image.
  4. Download the optimized file.

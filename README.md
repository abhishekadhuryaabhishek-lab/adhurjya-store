# Adhurjya Store – Client-Side Photo & PDF Toolbox

Adhurjya Store is a fully client-side, privacy-friendly web app packed with powerful tools for photos, PDFs, media, OCR, signatures and more — all running 100% inside your browser.  
No server, no uploads, no login. Everything stays on your device.

## 🚀 Features

### 📸 Image Tools
- Photo → PDF Converter
- Photo Size Compressor
- Image Resizer
- Background Remover (solid color)
- Image Format Converter (JPG/PNG/WEBP)
- AI Photo Enhancer
- ID Photo Maker (passport / visa / 2×2 inch)

### 📄 PDF Tools
- PDF Compressor
- Merge PDF
- PDF → Image Converter
- 100% in-browser PDF generation via pdf-lib and pdf.js

### 🔤 OCR Tools
- Image to Text (OCR) using Tesseract.js  
  Supports English (eng), Hindi (hin), Bengali (ben)

### ✍️ Utility Tools
- Digital Signature Pad
- Audio-to-Text (Demo UI)

## 🧠 Technology Used
- HTML + CSS + Vanilla JavaScript  
- pdf-lib  
- pdf.js  
- Tesseract.js  
- Canvas API  

## 🔐 Privacy
✔ All processing is done locally in your browser  
✔ No data upload  
✔ Safe for personal documents & ID photos  

## 📱 Compatibility
Works on Android, Windows, macOS & all modern browsers.

## 📦 How to Run
Just open `index.html` in your browser.  
No installation required.
